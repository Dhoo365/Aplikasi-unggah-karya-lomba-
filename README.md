Sistem pengunggahan karya lomba berbasis android

Deskripsi Project

Aplikasi ini dirancang untuk mempermudah siswa dalam mendaftarkan diri dan mengunggah karya lomba, membantu guru dalam memantau peserta, membantu juri dalam melihat dan menilai karya, serta membantu admin dalam mengelola data lomba.

Project ini dibuat menggunakan Vue 3, Ionic Framework, dan Capacitor.


## Latar Belakang / Masalah

Proses pendaftaran dan pengumpulan karya lomba masih dapat dilakukan secara manual sehingga menimbulkan beberapa permasalahan, seperti:

- Peserta kesulitan mengetahui dokumen yang harus dikumpulkan.
- Guru kesulitan memantau siswa yang mengikuti lomba.
- Juri membutuhkan cara yang lebih terstruktur untuk melihat dan menilai karya.
- Admin membutuhkan sistem untuk mengelola data peserta, karya, dan proses perlombaan.

Oleh karena itu, diperlukan sebuah aplikasi yang dapat mengintegrasikan proses pendaftaran, pengumpulan karya, pemeriksaan, dan penilaian dalam satu sistem.

## Scope MVP

MVP atau Minimum Viable Product pada aplikasi ini berfokus pada fitur utama yang dibutuhkan agar proses pendaftaran dan pengumpulan karya dapat berjalan.

### Fitur Siswa

- Registrasi akun.
- Login.
- Melengkapi data peserta.
- Memilih bidang lomba.
- Mengunggah dokumen persyaratan.
- Mengunggah karya.
- Melihat status pengumpulan.

### Fitur Guru

- Login.
- Melihat data siswa yang didampingi.
- Melihat status pendaftaran siswa.
- Memantau kelengkapan dokumen dan karya.

### Fitur Juri

- Login.
- Melihat daftar karya peserta.
- Melihat detail karya.
- Memberikan nilai.
- Memberikan catatan penilaian.

### Fitur Admin

- Login.
- Mengelola data pengguna.
- Memverifikasi peserta.
- Mengelola bidang lomba.
- Mengelola data karya.
- Melihat hasil penilaian.
